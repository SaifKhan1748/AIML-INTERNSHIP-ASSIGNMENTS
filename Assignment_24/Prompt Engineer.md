# Assignment (30/03/2026) 

# Assignment Name : Prompt Engineer 
# Description : Write prompts for resume, business idea, study plan and compare weak vs strong prompts.


# 1. Resume Prompt
# ❌ Weak Prompt:
- “Make my resume”
# 👉 Problem:
- No details provided
- Output will be generic

# ✅ Strong Prompt:
    “Create a professional resume for a BCA student with skills in Python, Machine Learning, and Data Analysis. Include sections for education, projects, skills, and internships. Keep it one page.”
# 👉 Improvement:
    - Clear role
    - Specific skills
    - Structured output

# 2. Business Idea Prompt
# ❌ Weak Prompt:
- “Give business ideas”
# 👉 Problem:
- Too vague
- No direction

# ✅ Strong Prompt:
    “Suggest 3 low-budget business ideas for college students in India related to AI or tech, including estimated cost, target audience, and profit potential.”
# 👉 Improvement:
    - Target audience defined
    - Budget mentioned
    - Detailed output expected

# 3. Study Plan Prompt
# ❌ Weak Prompt:
- “Make a study plan”
# 👉 Problem:
- No timeframe or subject

# ✅ Strong Prompt:
    “Create a 30-day study plan for learning Data Science for a beginner, covering Python, statistics, and machine learning with daily tasks of 2 hours.”
# 👉 Improvement:
    - Timeframe specified
    - Subjects included
    - Daily structure given
