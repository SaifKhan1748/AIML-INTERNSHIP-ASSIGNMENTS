# 📄 Image Filter Lab

## 📌 Overview
This project demonstrates basic image filtering techniques using OpenCV. It applies grayscale conversion, blurring, and edge detection to an image and displays the results for comparison.

---

## 🎯 Features
- Convert image to grayscale  
- Apply Gaussian blur  
- Detect edges using Canny edge detector  
- Display original and processed images  

---

## 🧰 Technologies Used
- Python  
- OpenCV  
- Matplotlib  

---

## ⚙️ Installation & Setup

### 1. Install Libraries
pip install opencv-python matplotlib

### 2. Project Structure
image-filter-lab/
│
├── app.py
└── sample.jpg

### 3. Run the Code
python app.py

---

## 💡 How It Works
- The image is loaded using OpenCV  
- Grayscale conversion reduces the image to one channel  
- Gaussian blur smooths the image and reduces noise  
- Canny edge detection highlights object boundaries  

---

## 📊 Output
The program displays:
- Original Image  
- Grayscale Image  
- Blurred Image  
- Edge Detected Image  

---

## 🧠 Key Concepts

### 🔹 Grayscale
Converts color image into a single channel (intensity only)

### 🔹 Blur
Reduces noise and smooths the image

### 🔹 Edge Detection
Detects sharp changes in intensity (edges)
